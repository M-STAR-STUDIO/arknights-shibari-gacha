RULES

縛りルール集引いた12体をもっと楽しむために

← ガチャに戻る 遊び方ガイド 更新履歴

アークナイツ縛りガチャの基本は「引いた12体をそのまま編成として使う」だけです。ただ、慣れてくると手持ちの育成状況によっては簡単すぎたり、逆に理不尽に感じたりすることがあります。このページでは、基本ルールに足し引きして難易度を調整するための追加ルールをまとめました。気に入ったものを1つか2つ組み合わせるのがおすすめです。

難易度の目安は、通常の育成済みアカウントで恒常ステージ(第6章〜第9章程度)に挑む場合を想定した5段階です。

BASIC

基本編

1. 基本ルール: 引いた12体をそのまま使う 難易度 ★★☆☆☆

ガチャで引いた12体をそのまま編成に入れ、それ以外のオペレーターは使いません。持っていないオペレーターがいた場合は「選んで再抽選」で同じレア度から引き直します。

  • 向いている場面: はじめての縛りプレー。恒常ステージの再攻略。
  • 注意点: 回復役がいない、地上ユニットが少ないなどの偏りが出ることがあります。それも含めて楽しむルールです。

2. 引き直しなし 難易度 ★★★☆☆

「選んで再抽選」を使いません。持っていないオペレーターが出た場合、その枠は空けたまま挑みます。

  • 向いている場面: 手持ちが充実しているアカウント。運の要素を強くしたいとき。
  • 注意点: 無双モードでは持っていない星6が並びやすく、極端に人数が減ることがあります。ノーマル以下で遊ぶ方が安定します。

3. 上から6体だけ使う 難易度 ★★★☆☆

12体のうち、スロット1〜6の6体だけを使います。残りの6体は控えとして扱い、出撃させません。

  • 向いている場面: 低コストで短いステージ。危機契約の練習。
  • 注意点: 使う6体を自分で選ぶと縛りが緩くなるので、必ず引いた順で決めます。

4. 職分を1つ選んで使う 難易度 ★★★★☆

引いた12体の中で、最も多かった職分のオペレーターだけを使います。同数の場合はスロット番号が小さい方の職分を採用します。

  • 向いている場面: 手持ちが多く、通常の縛りでは物足りないとき。
  • 注意点: 前衛や狙撃が最多ならなんとかなりますが、補助や医療が最多になると成立しないステージが多くなります。無理なものは潔く諦めるルールです。
BUILD

育成制限編

5. 昇進1まで 難易度 ★★★☆☆

昇進2にしているオペレーターも、昇進1相当の性能として扱います。実際にはレベルを下げられないので、昇進2で解放されるスキル(第3スキル)とモジュールを使わない、という形で運用します。

  • 向いている場面: 序盤〜中盤のステージを新鮮な気持ちでやり直したいとき。
  • 注意点: 昇進2の素質は残ってしまうため、完全な再現ではありません。厳密にしたい場合は「昇進1のオペレーターが出たらそのまま、昇進2は第1・第2スキルのみ」と決めておくと運用しやすいです。

6. スキル特化なし 難易度 ★★☆☆☆

スキルレベルは7まで(特化なし)として扱います。特化済みのスキルは使わず、特化していないスキルを選びます。

  • 向いている場面: 特化前提の戦術に頼りがちな人。
  • 注意点: 全スキルを特化しているオペレーターは、そのオペレーター自体を使わないか、第1スキルに固定するなど、事前に決めておきます。

7. モジュール禁止 難易度 ★★☆☆☆

モジュールを装備しているオペレーターは、出撃前に外します。

  • 向いている場面: モジュール実装前のステージ設計を味わいたいとき。
  • 注意点: 外し忘れに注意。編成画面で装備を確認してから出撃します。

8. 第1スキル固定 難易度 ★★★☆☆

全員のスキルを第1スキルにします。普段は使わないスキルの使いどころを考えることになります。

  • 向いている場面: 星6の第3スキルに頼りがちな編成が出たとき。
  • 注意点: 第1スキルが自動発動系のオペレーターは、意外と強いことがあります。逆にほとんど機能しないオペレーターもいて、格差が大きい縛りです。

9. スキルもガチャで決める 難易度 ★★★★☆

各オペレーターのスキルを、スロット番号を使って決めます。スロット番号を3で割った余りが 1 なら第1スキル、2 なら第2スキル、0 なら第3スキル。該当スキルがない場合は第1スキルです。

  • 向いている場面: 同じ12体で何度も遊ぶとき、2周目以降の変化を付けたいとき。
  • 注意点: シェア画像にはスロット番号が入っていないので、ゲーム側で編成する前にスロット番号とスキルの対応をメモしておきます。
TACTICS

戦術制限編

10. 支援ユニット禁止 難易度 ★☆☆☆☆

フレンドの支援オペレーターを編成に入れません。多くの人が自然に守っているルールですが、明文化しておくと迷いがなくなります。

  • 向いている場面: すべてのルールの前提として。
  • 注意点: 特になし。12体だけで完結させるのが縛りガチャの趣旨です。

11. 撤退禁止 難易度 ★★★☆☆

一度配置したオペレーターは、倒されるまで撤退させません。再配置前提の戦術が使えなくなります。

  • 向いている場面: 特殊(快速支援など)が多く出て、撤退戦術が強すぎると感じたとき。
  • 注意点: 配置ミスがそのまま敗北につながります。配置位置をよく考える練習にもなります。

12. 引いた順に配置 難易度 ★★★★☆

スロット1のオペレーターから順番に配置します。コストが足りない場合は貯まるまで待ちます。撤退したオペレーターは最後尾に回ります。

  • 向いている場面: 手持ちが強すぎて何をしても勝ててしまうとき。
  • 注意点: 先鋒が後ろの方に固まると序盤が非常に苦しくなります。難易度の高い縛りなので、簡単なステージから試すのがおすすめです。

13. 医療を使わない 難易度 ★★★☆☆

医療オペレーターが引かれても出撃させません。回復は前衛や重装の自己回復、補助の回復効果などに限られます。

  • 向いている場面: 引いた編成に医療が3体以上入っていて、逆に簡単に感じるとき。
  • 注意点: 長期戦のステージでは成立しにくいので、短いステージや殲滅作戦の序盤で試すとちょうどよい難易度になります。

14. 星6は2体まで 難易度 ★★★☆☆

星6が3体以上引かれた場合、スロット番号が小さい2体だけを使い、残りの星6は出撃させません。イージーで引いたときに難易度を上げるためのルールです。

  • 向いている場面: イージーやノーマルで引いたが、少し手応えが欲しいとき。
  • 注意点: 無双モードとは組み合わせられません。
CONTENT

コンテンツ編

15. 殲滅作戦を引いた編成でクリアする 難易度 ★★★☆☆

週の殲滅作戦(400体)を、引いた12体だけで完走します。

  • 向いている場面: 毎週の合成玉集めを少しだけ緊張感のあるものにしたいとき。
  • 注意点: 失敗すると時間を失うので、余裕のある週に。慣れてきたら難易度を上げていくのが楽しみ方です。

16. 素材周回を引いた編成で回す 難易度 ★★☆☆☆

その日の素材ステージを、引いた編成で理性がなくなるまで周回します。自動指揮を作れれば成功です。

  • 向いている場面: 毎日の周回が作業になっているとき。
  • 注意点: 自動指揮が安定しない編成のときは、無理せず翌日に持ち越します。

17. 危機契約に持ち込む 難易度 ★★★★★

危機契約の常設ステージに、引いた12体で挑戦します。契約はまず0から始め、クリアできたら少しずつ上げていきます。

  • 向いている場面: 縛りガチャに慣れて、最高難易度を求めるとき。
  • 注意点: 契約を上げるほど特定の職分が必須になります。到達できた等級を記録しておくと、次に引いた編成との比較が楽しめます。

18. 1週間同じ編成で過ごす 難易度 ★★★☆☆

月曜に引いた12体を、1週間のデイリー・ウィークリーのすべてに使います。イベントステージも同じ編成で挑みます。

  • 向いている場面: 日々のプレイ全体に変化を付けたいとき。
  • 注意点: シェア画像を保存しておくと、週の途中で編成を忘れません。イベントの高難易度ステージは、必要なら縛りを解除する日を決めておくと続けやすいです。
SOCIAL

みんなで遊ぶ編

19. 同じ12体で同じステージに挑む 難易度 ★★☆☆☆

シェア画像を友人に送り、同じ12体(持っていないオペレーターは各自で近いものに置き換え)で同じステージに挑み、クリアの可否や配置の違いを比べます。

  • 向いている場面: 友人と一緒に遊ぶとき。配信や動画の企画。
  • 注意点: 置き換えの基準(同じ職分・同じレア度など)を先に決めておくと揉めません。

20. 難易度を上げていく 難易度 ★★★★☆

イージーで引いた編成で目標ステージをクリアしたら、次はノーマル、その次は Mon3tr と、難易度を1段ずつ上げて同じステージに挑みます。

  • 向いている場面: ひとつのステージを深く遊びたいとき。
  • 注意点: Mon3tr は星1・2が10%の確率で入るので、そこまで到達できたら十分に上級者です。
